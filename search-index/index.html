Search index

The files behind Search, built with the site: 2,443 documents split into 4,049 passages and 10,472 terms. The page loads meta.json and p.json, then only the shards a query needs.

The format is documented at the top of site/sitelib/searchindex.py: meta.json (shard map and stop words), p.json (document table and passage lengths), i-*.json (postings by term prefix) and d-*.json (passage text).
