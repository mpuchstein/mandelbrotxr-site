Extract the html file from all chats into a folder named {Providername}-{Tool}-{Model}-{Thinkinglevel/Effortlevel}-{Prompt version} using Claude in Chrome. Example for the first chatgpt link: OpenAI-Web-GPT6-Pro-v0 Extract the full chat transcription also into that folder as TRANSCRIPTION.md Save both prompts into the project root as prompt0.txt and prompt1.txt

When that is done add, commit and push this repo. then create a folder Review in this folder. there you create 3 folder: HTML-Review TRANSCRIPT-Review Browser-Review

for each chat that we exported start 3 Opus xhigh Agents:

  1. one agent that just looks at the html file we extracted. he delivers a REVIEW.md to Review/HTML-Review/{Providername}-{Tool}-{Model}-{Thinkinglevel/Effortlevel}-{Prompt version}. You save its chat transcript to TRANSCRIPT.md in Review/HTML-Review/{Providername}-{Tool}-{Model}-{Thinkinglevel/Effortlevel}-{Prompt version}. It's prompt gets saved to Review/HTML-Review/{Providername}-{Tool}-{Model}-{Thinkinglevel/Effortlevel}-{Prompt version}/PROMPT.txt
  2. one agent that just looks at the transcript we extracted. he delivers a REVIEW.md to Review/TRANSCRIPT-Review/{Providername}-{Tool}-{Model}-{Thinkinglevel/Effortlevel}-{Prompt version}. You save its chat transcript to TRANSCRIPT.md in Review/TRANSCRIPT-Review/{Providername}-{Tool}-{Model}-{Thinkinglevel/Effortlevel}-{Prompt version}. It's prompt gets saved to Review/TRANSCRIPT-Review/{Providername}-{Tool}-{Model}-{Thinkinglevel/Effortlevel}-{Prompt version}/PROMPT.txt
  3. one agent that looks at the html file in Claude in Chrome. here it is important to have them run sequentially. you open an python server for the test, then you start the agent. he delivers a REVIEW.md to Review/Browser-Review/{Providername}-{Tool}-{Model}-{Thinkinglevel/Effortlevel}-{Prompt version}. You save its chat transcript to TRANSCRIPT.md in Review/Browser-Review/{Providername}-{Tool}-{Model}-{Thinkinglevel/Effortlevel}-{Prompt version}. It's prompt gets saved to Review/Browser-Review/{Providername}-{Tool}-{Model}-{Thinkinglevel/Effortlevel}-{Prompt version}/PROMPT.txt

This prompt and your chat transcript needs to be saved to ReviewOrchestrator/{PROMPT,TRANSCRIPT}.md
