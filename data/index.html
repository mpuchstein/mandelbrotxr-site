Data

The complete results as machine-readable files: one JSON export with everything and three flat CSV tables. They are generated from the repository at commit 75d36a02e1f0 (2026-10-30) by the same build that writes this site, so every number here equals the one on the pages.

Files

  • results.json

    JSON · 118.5 kB
    8 candidates · 24 reviews · 5 judges

    Everything in one file: candidates, reviews with criteria, judge rankings with verbatim justifications and special elements, and the derived metrics.

  • ranks.csv

    CSV · 3.2 kB
    40 rows

    One row per judge × ranked candidate, by judge, then rank.

  • scores.csv

    CSV · 1.8 kB
    24 rows

    One row per phase-1 review, by review type, then folder.

  • criteria.csv

    CSV · 34.4 kB
    144 rows

    One row per criterion of every phase-1 review, in the review's table order.

UTF-8, \n line endings. CSVs have a header row and RFC 4180 quoting; JSON keys keep the order documented below. Two builds of the same commit produce byte-identical files.

Provenance and licence

  • Source: the committed files of mpuchstein/MandelbrotXR at 75d36a0:
    • site/candidates.toml: the candidate list (the only file entered by hand)
    • Review/*-Review/*/REVIEW.md: every phase-1 review
    • Judge/*-Judge/RANKING.md: every judge ranking
    • Judge/judge-mapping.json: the judges' letter mapping
    • ReviewOrchestrator/blind-mapping.json: the reviewers' blind ids
    • ReviewOrchestrator/blind/source-html.sha256: checksums of the blinded HTML copies
  • Verdicts are verbatim: justifications, reasons and special-element bullets are the judges' and reviewers' Markdown, unchanged. Scores and ranks are parsed, not edited.
  • Fields marked derived are computed by the build; see Derived fields and Methodology.
  • The repository has no licence file at this commit; reuse terms are the repository owner's.

results.json schema

A single object. Paths are repository-relative; urls and url fields are site paths relative to the site root. Integers stay integers; other numbers are rounded to 4 decimals.

Derived fields derived

The judges produced ranks and the reviewers produced scores; everything under derived is computed by this site from those numbers:

  • Mean rank = sum of a candidate's ranks ÷ number of judges that ranked it. display rounds to one decimal, as in Judge/README.md; exact is the fraction, so ties are exact (equal fractions = tie).
  • Standing: competition rank by mean rank (1, 1, 3, …) among candidates ranked by every judge; tied marks shared places.
  • Spread: min and max rank, and σ = √(Σ(r − mean)² / n), the population standard deviation.
  • Kendall τb between two judges over the candidates both ranked: (C − D) / √((C + D + Ta)(C + D + Tb)).
  • external and alert_calls come from scanning each product file for absolute resource URLs and alert( calls.
