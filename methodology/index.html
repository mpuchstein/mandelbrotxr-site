Caveats

Pipeline

The process ran in 5 stages. Each box names the scripts that implemented it (linked to their source) and what it wrote to the repository. The step-by-step account is ReviewOrchestrator/README.md §2 “Steps” GitHub; extraction itself was done by the orchestrator in the browser, with claude2md.py only for the claude.ai conversation exports.

  1. Extract. Tools: claude2md.py GitHub. Outputs: 8 candidate folders, each with a product .html and TRANSCRIPTION.md; prompt0.txt, prompt1.txt.
  2. Blind. Tools: blind.py GitHub, judge_blind.py GitHub. Outputs: blind-mapping.json (candidate-NN); blind/: anonymized transcripts and sha256 lists; judge-mapping.json (letters).
  3. Review. Tools: prompts.py GitHub, finalize.py GitHub, jsonl2md.py GitHub, redact.py GitHub. Outputs: 24 reviews of 3 types: REVIEW.md, PROMPT.txt, agent log, screenshots.
  4. Judge. Tools: judge_prompts.py GitHub, judge_finalize.py GitHub. Outputs: 5 judgments: RANKING.md, MAPPING.md, PROMPT.txt, agent log, screenshots.
  5. Aggregate. Tools: judge_aggregate.py GitHub. Outputs: rank table in Judge/README.md; derived metrics on this site.

Other tools in tools/ that are not a pipeline stage: user_prompts.py GitHub.

Environment limits

  • Device: desktop Chrome, no XR headset and no WebXR emulator.
  • Viewport: the window manager kept the viewport at about 446 px wide and would not resize below it; the phase-2 judges used a 390×844 iframe instead.
  • Frame rate: Chrome throttled background windows, so several reviewers could not judge frame rate.
  • XR entry: no real VR or AR session was entered.

The list above restates the two passages below; the passages are the source.

Derived metrics

The judges produced ranks only. Everything below is computed by this site from those ranks; none of these numbers comes from a judge or reviewer.

Mean rank derived

mean = (r1 + … + rn) / n

over the n judges that ranked the candidate (a judge that did not rank it is left out). Shown to one decimal. Equal means are shown as ties; the place is a competition rank (1, 1, 3, …).

Worked example for Opus 5.5 · v1: ranks 1, 2, 1, 4, 1 → mean = 9 / 5 = 1.8; spread 1–4; σ = 1.17.

Spread and σ derived

spread = min(r) to max(r)  ·  σ = √( Σ (ri − mean)² / n )

σ is the population standard deviation of the candidate's ranks: 0 means every judge agreed; larger values mean the judges disagreed more.

Kendall τb derived

τb = (C − D) / √( (C + D + Ta) · (C + D + Tb) )

for two judges, over every pair of candidates both ranked: C = pairs ordered the same way, D = pairs ordered oppositely, Ta/Tb = pairs tied in only one judge's ranking. +1 = identical order, 0 = unrelated, −1 = reversed.

Example: HTML vs Transcript over 8 common candidates, τb = 0.64.

The tables and charts are on Rankings; the mean column reproduces the table in Judge/README.md GitHub. Phase-1 overall scores are the reviewers' own numbers, taken as the first number on each review's overall-score line.

Reproducing

From ReviewOrchestrator/README.md “6. Reproducing the pipeline” GitHub, verbatim:

The scripts take paths as arguments and use only the standard library. Run them with python3 -I.

  • claude2md.py <conv.json> <out.md> <header>: renders a claude.ai conversation export.
  • blind.py <repo> <scratch>/blind: builds the shuffled anonymous candidate copies and the mapping.
  • prompts.py <repo> <scratch>: writes the 24 PROMPT.txt files. The port and dialog-stub edits described in 3.2 and 3.3 were applied to the saved files afterwards.
  • finalize.py <repo> <scratch> {html|transcript|browser} [candidate-NN…]: copies the reviews and renders the agent logs.
  • jsonl2md.py <session.jsonl> <out.md> <header>: renders a Claude Code session log.
  • redact.py <session.jsonl> <private-terms.txt> <files…>: redacts leaked personal strings in place.
