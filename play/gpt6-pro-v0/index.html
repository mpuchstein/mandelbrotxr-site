COMPUTING
A FIELD GUIDE

One equation.
An endless landscape.

z0 = 0   ·   zn+1 = zn2 + c

The Mandelbrot set contains the complex numbers c whose orbits remain bounded. This exhibit samples the complex plane and raises each point according to its smooth escape time. The warm upper plateau marks samples that did not escape within the selected iteration limit. The main cardioid and period-two bulb are tested analytically; elsewhere, a finite test cannot prove membership.

The set itself is two dimensional. Here, the third dimension encodes a measurement: it is a relief of the Mandelbrot set, with real geometry, lighting, parallax, and stereo depth. Smaller features can be missed at finite mesh resolution.

OPENING THE FILE

All scripts and graphics are embedded. Ordinary 3D viewing needs no network connection after downloading. Some phone file-preview apps do not execute HTML: open it in a real browser, or serve this same file as a static HTTPS page.

For headset VR or mobile AR, open an HTTPS URL in a browser with WebXR support and grant its requested access. http://localhost may also work on the same device. An ordinary http://192.168… address is not a secure origin. Local-file XR policies differ across browsers. If embedding this page in another site, the frame must allow XR spatial tracking; opening it directly is preferable.

DEVICE SUPPORT

Immersive sessions are offered only when this browser reports support. Quest and PICO browsers can provide WebXR; Steam Frame requires a compatible browser and XR runtime. Android AR requires a supported device/browser and its AR services. iPhone/iPad browsers use the touch or motion room where immersive WebXR is absent. AR glasses must expose WebXR; display-only glasses have no tracking API for this page to use.

Choose Enter AR · full-size room to enter the gallery around your tracked viewpoint. The room appears at human scale, with floor-ring teleportation and the same controls as VR. Alternatively, Enter AR · tabletop exhibit shows an open miniature gallery, initially in front of you. Move the phone or headset, then select Place gallery here (or select once in the world) to fix it at that location. Placement uses a position relative to your tracked view, followed by a confirmation step. It does not claim to detect tables or walls.

PHONE STEREO

Optional side-by-side stereo is available for simple phone viewers or display glasses. Use landscape orientation. It has no lens-distortion correction or positional tracking and is separate from WebXR. Exit via the on-screen button or Escape.

UNDER THE HOOD

Three.js r186 and its native WebXRManager are bundled in this file. Mozilla’s old three.xr.js is archived and uses obsolete browser APIs; this implementation replaces it with current WebXR plus an embedded session/input helper. Fractal sampling runs in an inline worker; rendering reuses the resulting mesh. No CDN, analytics, external models, fonts, or textures are requested.

Reference: Three.js WebXRManager · WebXR browser requirements · Legacy three.xr.js

Light: 128 × 96 cells / 192 iterations. Balanced: 192 × 144 / 320. Fine: 288 × 216 / 640. Height uses a log-normalized smooth escape count. WebGL 2 is required.
