Perturbation deep zoom

A high-precision reference orbit computed on the CPU, with low-precision deltas iterated on the GPU, to zoom past float32 limits.

4 bullets from 3 judges · 2 candidates named

Opus 5.5 · v1 ×3 (3 bullets)Opus 5.5 · v0 ×3 (3 bullets)

  1. H, E — perturbation-theory deep zoom (float64 CPU reference orbit in an RG32F texture, float32 GPU deltas, row-scissored progressive jobs, cross-faded buffers): the only candidates that zoom past float32 limits, to roughly 1e-12 to 1e-13.

    HTML judge · H → Opus 5.5 · v1; E → Opus 5.5 · v0 · RANKING.md, line 27 GitHub

  2. A, B — perturbation deep zoom: both compute a float64 reference orbit on the CPU, upload it as an RG32F texture and iterate fp32 deltas with Zhuoran rebasing on the GPU, which goes orders of magnitude deeper than every other candidate's naive float32 escape-time.

    HTML + Transcript judge · A → Opus 5.5 · v0; B → Opus 5.5 · v1 · RANKING.md, line 26 GitHub

  3. G, perturbation deep zoom: a float64 CPU reference orbit with Zhuoran rebasing let the Dive button run to 1.96×10¹⁰ while the terrain still rendered, far past the roughly 10⁵ limit where plain float32 shaders break down.

    Browser + HTML judge · G → Opus 5.5 · v1 · RANKING.md, line 27 GitHub

  4. H, deep tour with float64 reference orbit and PBO readback: the tour stop "Seahorse valley" at width 3×10⁻⁹ rendered crisp spirals on both the wall screen and the terrain, and async readback keeps ray-picking from stalling the frame.

    Browser + HTML judge · H → Opus 5.5 · v0 · RANKING.md, line 28 GitHub
