Two phases, two blinding schemes

Phase 1 · reviews

3 review types (HTML, Transcript, Browser) × 8 candidates. Each reviewer saw one candidate, under a blind id candidate-NN, and scored it alone against a shared rubric, ending with an overall score.

Blinding: one seeded shuffle of the candidate folders onto candidate-NN ids, shared by all review types. The mapping is ReviewOrchestrator/blind-mapping.json GitHub.

Blind setup (tools/blind.py): the 8 folders were shuffled with a fixed seed into candidate-01…08, using copies of the HTML (as index.html) and anonymized transcripts (identifying header dropped; vendor, product and model names replaced). blind-mapping.json holds the mapping. blind/ contains exactly the transcripts the reviewers read. blind/*.sha256 shows that the HTML copies are byte-identical to the sources.

ReviewOrchestrator/README.md, line 31 GitHub

Prompts (tools/prompts.py): one template per review type with a shared 6-criterion 1–10 rubric, the matching prompt version quoted, and output written to a blind path. Each prompt was saved as PROMPT.txt before its agent launched. For every agent, the prompt in its log matches its PROMPT.txt; tools/finalize.py checks this.

ReviewOrchestrator/README.md, line 32 GitHub

Phase 2 · judges

5 judges, each with different material, saw all candidates side by side under letters (A–H) and produced one comparative ranking.

Blinding: a separate seeded shuffle per judge onto letters, so the same letter means a different candidate for each judge. The mapping is Judge/judge-mapping.json GitHub; each judge folder also has a MAPPING.md written after the judge finished.

Five judges each ranked all 8 implementations from best to worst. This is phase 2; the per-candidate reviews from phase 1 are in ../Review/, and the process log is in ../ReviewOrchestrator/README.md.

Judge/README.md, line 3 GitHub

Blinding: each judge had its own seeded shuffle onto the letters A–H (../ReviewOrchestrator/tools/judge_blind.py; seeds 101/202/303/404/505). The judges saw only their own scratch folder, not this repo. Transcripts were anonymized with the same function as in phase 1. HTML copies are byte-identical to the sources, except for the one patch below.
